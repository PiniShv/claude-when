Why When

Claude Code shows no time on its messages. So in a long session, you cannot tell when you asked something, or how long a step took. When puts the date and time on every message. It also tells Claude when each prompt was sent, so Claude can answer from real times.

Three places. One clock.

The time shows on screen. Claude gets it too.

On screen

Your messages.

Each message you send gets its date and time above it, in your local time.

On screen

Claude's replies.

Each reply gets one too. A reply's time is when Claude started writing it.

In the model's view

Claude's own sense of time.

When tells Claude when each prompt was sent. Ask how long a step took and Claude answers from real times.

Good to know.

What When does not do, said up front.

  • Image-only messages get no time.

    A message that is only an image, with no text, gets no time.

  • Older messages get no time.

    Messages from before you installed When get no time.

  • Desktop, terminal and VS Code.

    It is verified in the Claude Code desktop app, in the terminal and in the VS Code panel. You need a Claude Code version that supports mods.

Install When.

Pick the way you use Claude Code. It is free.

Desktop app

Click + next to the prompt box, then Plugins, then Add marketplace. Enter this:

> PiniShv/claude-when

Then click Add plugin.

Terminal session
> /plugin install when --marketplace PiniShv/claude-when

Type it in a Claude Code session.

Shell
$ claude plugin install when --marketplace PiniShv/claude-when

Run it in your shell.

To remove it
$ claude plugin uninstall when@claude-when

Messages from before you installed When get no time. See the limits.

Questions before you install.

Does it send data anywhere?

No. When has no network calls, no telemetry and no account. It reads the computer's clock and keeps one time per message on your computer. Nothing leaves it.

Does it change my chat history?

No. The transcript is not changed. The time line is drawn on screen only.

Which app does it work in?

It works in the Claude Code desktop app, in the terminal and in the VS Code panel, and all three are verified. On the Claude mobile app you do not see the time line, but Claude still gets the send time of each message you type there. You need a Claude Code version that supports mods.

Why does an image-only message show no time?

When puts the time on messages that have text. A message that is only an image, with no text, gets no time. Messages from before you installed When get no time either.

How do I remove it?

Run this in your shell: claude plugin uninstall when@claude-when

What does it cost?

Nothing. When is free, under the Apache License 2.0.
